# Los Pollos Hermanos Restaurant Website

## Project Description

A responsive restaurant website built with React JS. It has a Home page, an About page, a Menu page and a Contact page with a validated contact form.

## Technologies Used

- React JS
- JavaScript (JSX)
- React Router
- HTML and CSS (Flexbox, Grid, media queries)
- Vite

## Features

- Page navigation with React Router
- Reusable components with props (MenuCard, InfoSection)
- Menu displayed with the .map() array method
- useState for interactive elements and form data
- Contact form with controlled inputs and validation
- Responsive design for mobile, tablet and desktop

## Installation

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Run: `npm install`
4. Start the application: `npm run dev`
